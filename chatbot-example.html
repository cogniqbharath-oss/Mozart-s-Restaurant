Chatbot Worker Integration Example

Welcome to the Chatbot Integration Demo

This page demonstrates how to integrate the Mozart's Restaurant AI Chatbot Worker into any page of your website. The chatbot is fully functional and ready to use!

💡 Try it out: Click the chatbot button in the bottom-right corner or use the demo buttons below to interact with the chatbot programmatically.

How It Works

The chatbot worker is included with just a few lines of code:

<!-- In the <head> section -->
<link rel="stylesheet" href="chatbot.css">

<!-- Before closing </body> tag -->
<script src="workers.js"></script>
<script src="script.js"></script>

Then include the chatbot HTML structure (see CHATBOT_README.md for details).

Advanced Features

  • ✅ Auto-initialization on page load

Programmatic Control

You can control the chatbot using JavaScript:

// Access the global chatbot instance
const chatbot = window.mozartChatbot;

// Send a message
chatbot.sendMessage("Hello!");

// Add quick suggestions
chatbot.addQuickSuggestions([
  "Make a reservation",
  "View menu"
]);

// Get conversation history
const history = chatbot.getHistory();
